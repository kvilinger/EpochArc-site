OpenAI and Cisco Unveil AI-Assisted Linux Security Tool to Block Exploits Before Patching
Ravie LakshmananNov 24, 2026Artificial Intelligence / Vulnerability
OpenAI and Cisco have teamed up to launch Shirudo (meaning "shield" in Japanese), an open-source Linux runtime that allows artificial intelligence (AI) agents to defend systems without downtime.
"It lets agents write dynamic eBPF controls to shield systems from exploits, giving defenders more time to test and roll out patches," OpenAI said in a post on X.
The AI upstart called the initiative a "first step" toward "self-defending infrastructure" that can adapt itself to new threats while the services continue to run and enable defenders to test and deploy fixes without any disruption.
The development comes as AI is accelerating vulnerability discovery, finding critical bugs in foundational software used to power internet-connected software.
Shirudo is being pitched as a way for defenders to test temporary safeguards (aka shields) and check if they block behavior that exposes a vulnerability, while letting legitimate requests pass through. Once a shield is approved by an operator, it can be deployed without having to stop the service.
The idea is to avoid a complete service disruption to block a line of attack simply because both an exploit and a legitimate request may rely on the same underlying Linux operation.
To achieve this, Shirudo makes use of eBPF (short for extended Berkeley Packet Filter), a technology that makes it possible to run lightweight, sandboxed programs inside the kernel without the need for modifying the system code or restarting it.
"eBPF is a highly efficient, sandboxed virtual machine in the Linux Kernel," Cisco's Isovalent said. "These eBPF programs allow you to interact with the Linux kernel to observe and take action on any events happening on a machine. Some use eBPF to simply observe everything on their system, others use it to enforce policies (routing, security, and more)."
Notably, Shirudo is built atop the foundations of Tetragon, an eBPF-based security platform that Isovalent developed and open-sourced in May 2022. The crucial difference is that it's primarily designed for agents and leverages the capabilities of eBPF to inject code mitigations.
Central to Shirudo is a guardian agent that uses eBPF shields to block vulnerable code paths without restarting the system, while giving security teams the flexibility to monitor how a proposed shield would affect the application before enforcing it. The shields are also cryptographically signed and verified prior to being loaded.
"Agents scan open-source code and take in vendor disclosures," Cisco said. "They trace each vulnerability to the affected assets and attack paths, then write a small, targeted shield. They check that the shield covers the exploit and that the service still runs. The shield only graduates to active blocking when the evidence says it's safe, and it retires when the real patch lands."
This involves the following steps -
An agent is tasked with finding new vulnerabilities in an application, or working off external sources of new vulnerability disclosures.
Shirudo on the operator machine builds a security shield consisting of eBPF or application bytecode after reproducing and validating the exploit.
The shield is delivered as signed .bee packages via an OCI-compliant registry.
The Shirudo layer on each target pulls these .bee packages, validating each signature using TPMs to establish trust and safety.
In a controlled experiment, a Codex-generated shield blocked a Java4Shell exploit attempt against a running Elasticsearch service without requiring a restart, OpenAI said.
OpenAI and Cisco said the goal is to fight AI-based threats with AI and counter the risks posed by AI-driven attacks as soon as a vulnerability is identified at machine speed.
"We need this kind of machine-speed defense because AI models have become incredibly good at finding and exploiting software vulnerabilities, and they get better with every generation," Thomas Graf, CTO of Cisco Security, and Liz Rice, chief open source office at Isovalent, said. "They can also chain flaws together and discover creative new attack vectors that no one has thought about before."
"Yet a critical fix in widely-used software, from the Linux kernel to the libraries every application depends on, still takes days, weeks, or even months to reach the majority of systems. That timeframe is no longer acceptable given that the mean time to exploitation has become negative."
