Z.ai launches GLM-5.4, its first Loop Transformer model
GLM-5.4 is live for all GLM Coding Plan users, looping 28 GLM-5 layers twice and adding vision, with 50% more weekly quota than GLM-5.3.

Z.ai has released GLM-5.4, its first flagship model built on a Loop Transformer architecture, and made it available to all GLM Coding Plan users, along with ZCode and Z.ai Chat. API access is listed as coming soon and will open after a safety evaluation, while the open weights are planned for release once safety hardening is complete. Z.ai says the model reaches intelligence levels comparable to 2T- to 3T-parameter models and adds vision capabilities for stronger visual coding. Zixuan Li of Z.ai said users with weekly quotas get 50% more GLM-5.4 quota than they had on GLM-5.3, with the model set as glm-5.4[1m] in Claude Code and glm-5.4 in other tools.

In a standard Transformer, each layer runs once per forward pass. GLM-5.4 runs 28 layers of the GLM-5 base model for two iterations, so the network gets deeper without adding parameters. Z.ai adapted the already pre-trained base through continued training, since looped models trained from scratch still trail unshared ones on the same compute budget. At the 750B scale, three changes keep deployment costs under control: per-token gates that decide how much each pass writes back into the residual stream, a hybrid KV cache where the extra loop costs one sliding window of cache instead of a full context cache, and reuse of the first pass's sparse attention indices.
On a 30B test model with about 10% more training compute, looping brought the largest gains in math, scientific reasoning and long-context tasks, and cut average output length by 10 to 14% on benchmarks such as GPQA-Diamond and MMLU-Pro. GLM-5.4 reaches up to 200 tokens per second off-peak and holds 70 to 80 at peak load.

Z.ai frames the release as the start of Generalized Coding, where code becomes the base for tasks well beyond software development. Its demos include a self-narrated music video called "Hello World", a 6-axis robotic arm modeled in FreeCAD, a complete game with physics, maps, combat and art assets, and an interactive 3D bird-watching scene built from pure geometry and custom GLSL shaders. The company is open about one limitation: the model tends to get caught in overly long "marathon thinking" loops, though Z.ai says this extra self-correction still lifts accuracy. No benchmark scores for GLM-5.4 itself have been published yet, and a Z.ai team member said they will come later.

Z.ai, also known as Zhipu AI, went all in on coding in early 2025 and has since moved through agentic engineering, long-horizon tasks and cybersecurity, the focus of GLM-5.3. GLM-5.4 reaches subscribers of its coding plan first, giving developers early access to the looped model inside their existing coding tools before the API opens. Z.ai says it will keep scaling loop depth and model size together, with a much larger next model coming soon. Early testers on X have already shared one-shot results comparing GLM-5.4 with far larger models.
