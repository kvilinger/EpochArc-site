# v2.4 校验覆盖与验收边界

v2.4 生产规则的实现与边界。测试入口 `npm run test:editorial`；校验入口 `python3 scripts/validate_all.py`。

## 机器与人工的分工

| 规则组 | 程序强制项 | 仍需语义/真实行为复核 |
|---|---|---|
| GOV-01/02 | policy 枚举/阈值读取；规则正文 rulesDigest；审核/校准绑定 policyDigest | 变更动机、是否得到负责人接受 |
| GOV-03 | 精确内容与依赖指纹；旧公开记录不能直接消失；slug/publishedAt 冻结 | 基线本身须代码审查保护，不能重生成规避 |
| GOV-04 / PUB-01 | human 类型、非空确认引用、精确 subject/review/policy 摘要、批准日期 | 人是否真实批准；不是密码学身份认证 |
| RUN-01 / DISC-01/02/03 | 批次时间窗/SHA/身份；full 的核心通道与六类覆盖；失败理由；请求留存哈希 | 是否实际完整覆盖窗口、失败描述是否属实 |
| DISC-04 / SCREEN | 候选 ID/五维/整数/总分/优先级/理由/低优先级例外 | 是否遗漏拒绝候选；每项分值的语义是否适当 |
| CONF | 四层对象、found 不为空、实际引用存在、事实层 found | 查询是否充分、材料是否真正证明事实 |
| IDENT / CLASS | 合法 stage、身份/比较理由、候选决定一致、次分类 claim 引用 | action 是否重复、分类是否反映核心动作、日期取法 |
| EVID | 摘录在文本中、路径/哈希、访问日期、原始起源/控制主体、主张来源匹配、等级上限 | 摘录上下文、利益关系、原始网站真实性、独立复测的真实性 |
| SIG | 规则 ID 与全部条件、布尔/整数/null、计数实体、独立验证、L2/L3 门槛、对照存在 | 新工作流/结构变化是否成立；组织是否确实无关联；L3 转折解释 |
| IMP | observed、日期与 timeframe、固定受众、severity 3 广度/时长、来源与证据等级、原公式复算 | 因果归因、materialChange、受众角色是否重叠、是否真的连续观察 |
| CONS | 共识标签理由；broad 的影响证据与独立起源；争议证据及 limitation | 主要反证是否遗漏、广泛接受是否真实成立 |
| REVIEW / LANG | 复核身份/日期/会话差异/模型、双语核对记录，必填中英字段 | 复核是否真实独立、翻译准确和表达自然 |
| ARC | 章节/锚点/跨度/公开引用，全部锚点和依赖摘要、额外来源及反例字段 | 论点、因果和反方处理是否充分 |
| DIR | 信号/事件引用、真实 screeningRunId、publish 决定、独立起源、monitor_only 生命周期 | 是否尚未成为常态、共识搜索是否充分、是否符合外部标准 |

不存在“机器通过即可省略右列”的例外。人工判断项仍是 MUST，只是目前不能由静态程序证明。

## 正反例范围

测试文件 `tests/test_editorial_policy.py`：

- 正例：正常 L1 无观察影响、L2 完整链、L3 多类别持续观察、定向批次、诚实的部分覆盖、未变历史记录、Arc 和方向复核。
- 反例：丢失筛选链、少通道/缺窗口、假 found、布尔代替数值、未知条件冒充满足、实体重复、错规则 ID、缺元数据、旧日期重写、缺访问日期。
- 来源：Tier 4 单源、仅报道冒充独立性能验证、同源转载、L3 独立计数误用 URL/来源默认字段、摘录不在留存件、内容被改、路径越界。
- 影响：预期后果入指数、时间档不符、未来观察期、受众同义词加分、severity 3 缺广度、neutral 掩盖混合影响、重复维度、公式正负/上界锚点。
- 生命周期：伪历史标记、删除旧公开记录、公开引用草稿、虚构方向 run、hold 方向试图公开、过期 subject/inputs/run/review/policy、AI 冒充 human 类型。
- 校准：冻结快照摘要、全部反事实路径重放、比较文件不能缺案例/复用会话、全部弃权不能产生评级一致率 100%。

这是有针对性的行为覆盖，不声称穷尽所有畸形 JSON、全部安全攻击或全部语义错误。

## 旧数据处理

当前基线包含 160 事件、4 方向、6 Arc。此前 Git 可核对的三处 publishedAt 元数据纠错已纳入基线，不是新事实审核。校验继续报告来源访问日期、百科 Tier、旧 provenance、旧证据等级和筛选链债务。

本轮不为这些债务改写来源、评级或发布时间。`audit_editorial.py` 输出离线结构债务；`governance/audits/2026-09-18-published.json` 是冻结清单。不能把 NO_V24_REVIEW 标签理解成该事件事实为假。

## 已知工程限制

- 人工批准引用是审计记录，不是签名服务；有仓库写权限者仍可伪造字段。因此 policy/baseline/approval 需负责人审查，不能盲信自动门禁。
- 来源记录或被引用事件变化会要求依赖内容复核，这是有意的严格策略；不允许为了避免连带复核复制旧哈希。
- 现阶段新 contract 使用 Python 规则校验而非 JSON Schema；非法结构失败关闭，错误可能只定位到 malformed contract，后续可改善字段级诊断。
- 现有公开前端消费格式基本保持不变；v2.4 受众 ID 先用于数据约束，展示标签独立处理。
- 跨模型协议和比较脚本已提供，尚无真实独立模型实验数据；不得宣称一致率目标已经达到。
