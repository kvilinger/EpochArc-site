# v2.4 校准与一致性验收

本轮完成的是**离线边界校准与可复现测试**，不是重新核实全部来源，也不是已经完成跨模型实验。

## 1. 固定材料

- 案例索引：`governance/calibration/cases.json`，绑定 policyDigest；policy 再通过 rulesDigest 绑定规则正文，防止只改文字定义却沿用旧校准。
- 16 个已上线事件完整快照：`governance/calibration/snapshots/*.json`，包含当时公开记录与来源登记，并绑定 snapshotDigest。
- 50 个明确标记 synthetic_counterfactual 的反事实/阈值案例。
- 测试的来源摘录、人工身份、审批全部为合成数据，只在临时目录创建，不是实际证据或批准。

16 个真实记录的旧等级只提供历史上下文。快照没有重新访问网页、没有补全独立来源起源、没有形成 v2.4 观察期证据，因此其可复现答案是 **review_required，最终等级暂不裁定**。这不表示这 16 个事件一定错，也不暗示应该降级。

## 2. 从已上线案例得到的边界修订

| 案例 | 原先易混淆的边界 | v2.4 处理 |
|---|---|---|
| Fujitsu MONAKA | 公告、将来发货与已产生能力/结构变化混为一谈 | stage 与已发生后果分开；计划不满足 L2 路径 |
| Sakana Fugu v2 | 独立确认 API 可用被当成性能复现 | 主张级 relationship/verification；不同验证对象分开 |

| Anthropic threat report | 公司报告即独立调查；只有事故路径 | 明确调查独立性；新增安全实践实际采用路径 |
| Kimi K3 | 发布公告就认为权重已开放；任一评测替代所有验证 | 区分宣布/开放/测评；新增访问权限变化路径 |
| Transformer / Turing | 全部用产品采用或新任务基准衡量基础研究 | 新增方法/框架的独立后续实际使用路径，不以引用数量代替 |
| ChatGPT | 热度/用户口径混用；先看到 L3 再找理由 | 独立活跃用户口径，跨类别实证持续性；旧等级不是答案 |

| AlphaGo | 把独立验证误解为必须从头重训闭源模型 | 可独立复测任务结果或审计第三方裁判的公开任务；不强求重训 |
| MCP | 根据旧 L1 默认后来也只能 L1 | 基于截止日的真实工作流/方法采用判断，不抄旧标签 |

以上判断针对**现有文本暴露的逻辑边界**，不是对外部事件真实性的新结论。

## 3. 数值门槛的地位

2 个无关联主体、100 万活跃用户、90/180/365 天均为版本化编辑政策，不是经实证证明的“历史重要性自然分界线”。选择理由是建立最低的外部性/持续性证据门槛，且提供多条替代路径，避免用同一规模指标压制基础研究或治理事件。

本轮做了：每条路径的全部条件通过、每个条件未知、每个数值略低于门槛；L3 的类别/时长/独立起源/控制主体边界；影响的时间档、受众去重及正负绝对量级测试。

本轮没做：通过独立模型样本或人工一致性统计证明这些数值最优。以后若出现真实有力反例，提交规则变更，不为单个品牌开例外。改 policy 会使冻结校准套件及已有 v2.4 批准失效，必须明确重新校准。

## 4. 重放

```bash
python3 scripts/calibrate_editorial.py
npm run test:editorial
```

当前索引为 66 个案例；重放检验结构化事实向量下的确定性分支，不等于测试模型读懂来源的能力。评级 positive/negative、Arc/方向、影响分及审批正反例在 Python 测试中另覆盖。

## 5. 跨模型实验协议（已定义，未执行）

1. 冻结政策、证据包、时间截止和提示词；分开记录“已有公开快照”和“真正逐来源核实的完整证据包”。
2. 至少两个真实模型，各开独立会话，不读取对方答案。不把同一会话分饰角色当成独立评审。
3. 给每个模型相同材料；评分答案/expected 不作为输入。旧标签不得作为正确答案。对真实快照，允许指出无法裁定及所缺证据。
4. 输出全部 caseId；未知保留 null，不能跳过难题提高一致率。发现召回率另测，不混入同证据决策一致率。
5. 比较决定、等级及影响分；报告分母、可评分覆盖率、弃权比例和具体分歧。不能因两个模型都弃权就说等级一致率 100%。
6. 人工抽查语义和硬规则违规，至少覆盖全部分歧案例；机器重放不证明模型没有乱解释证据。
7. 修订规则时版本递增，冻结旧结果并重新跑全部案例；不只回测有利案例。

统一提示词：

> 依据给定 EpochArc 政策和相同截止日的材料，先确定核心事实、动作阶段和未知项，再给出工作决定、主分类、适用评级路径、条件逐项证据、可支持等级和影响输入。不得联网补充未记录证据，不使用旧评级作为答案，不推测缺失数据。历史快照不足以重评时输出 review_required 与 significance=null；合成反事实只按其明确给定的已裁定事实向量评估。不得生成批准，不修改 canonical。列出最小补证需求及两个最接近的对照案例。

每个模型输出 JSON 顶层：`model/sessionId/suiteDigest/policyDigest/results`；results 每项：`caseId/decision/significance/impactIndex`，可附分类、规则、证据、理由和不确定性。identityDecision 只在合成样本明确给定时直接使用；真实身份判定仍须解释。

```bash
python3 scripts/calibrate_editorial.py --compare /path/model-a.json /path/model-b.json
```

程序检查相同套件/政策摘要、会话不同、全部案例恰好一次、枚举与数值合法；输出两两一致性与覆盖率。它不认证文件真的由指定模型生成，也不自动宣布 certified。

验收目标取自 policy.benchmarkTargets：决定一致率、等级一致率、影响分差不超过 1 的比例及硬规则违规数。**达到相似结果≠得到正确结论**；只有样本可评分、语义复核通过、无硬规则违规时才能讨论达标。目前状态是“未实测”，不是“已达标”。

## 6. 本轮停止边界

不更新任何公开等级，不对待发布草稿做评价，不补造来源访问或人类审批。本轮完成后，后续事实复核和评级迁移另立任务，不能以校准包代替重新读原始资料。
