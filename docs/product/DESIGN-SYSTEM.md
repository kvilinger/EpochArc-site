# EpochArc 页面设计系统

本规范是全站页面结构与视觉表现的唯一基准。首页可以保留入口页需要的居中叙事，其余页面统一使用同一套内容网格、返回导航、标题层级、信息模块和页脚。

## 1. 页面骨架

- 顶部导航：全站复用 `.topnav`，高度 64px；当前栏目使用 `aria-current="page"` 显示蓝色选中态。
- 非首页内容宽度：`--container: 960px`，左右留白由 `--gutter: 24px` 控制。
- 非首页页面：统一使用 `.site-page`。
- 返回入口：统一使用 `.page-back`，位置在标题区域之前；列表页返回时间轴，详情页返回对应列表。
- 页脚：统一使用 `.pagefoot`，只保留 RSS / Atom 与方法和来源两个入口。

## 2. 标题与阅读层级

- 非首页标题全部左对齐，使用 `.page-header`、`.page-kicker`、`.page-title`、`.page-lead`。
- 页面标题最大 48px；正文默认 15–16px，长文本行高 1.75–1.82。
- 元信息使用 `.page-meta-row` 或右侧信息栏，不在不同页面重新定义字号和间距。
- 首页可使用居中大标题，但页头、按钮、颜色、字体与页脚仍需遵循本规范。

## 3. 列表页

- 专题列表、方向列表均使用 960px 内容宽度和左对齐标题区域。
- 列表页必须有返回时间轴入口。
- 专题适合使用克制的双列内容卡；方向适合使用信息账本式列表。
- 卡片只承载可独立点击的内容对象，不用卡片包裹整个页面。

## 4. 详情页

- 桌面端统一使用 `.page-layout`：正文自适应，右侧信息栏固定 `--rail-width: 220px`，间距 `--page-grid-gap: 36px`。
- 右侧信息栏使用 `.page-rail`、`.rail-card`、`.rail-facts`，展示日期、状态、评分、时间跨度、事件数等快速事实。
- 专题详情：章节导航使用胶囊式横向导航；摘要使用单一强调模块；章节正文保持连续阅读。
- 方向详情：右栏展示窗口、证据、信号、来源和复核日期；正文展示基线、论点、信号、反向条件与来源。
- 事件详情：右栏展示日期、分类、重要度、共识和影响指数；正文展示摘要、影响、证据与关联事件。
- 方法页：右栏作为本页目录和统一定义说明；正文是全站规则的唯一来源。

## 5. 组件规则

- 胶囊：只用于返回、当前章节、状态和短标签；使用 `--radius-pill`。
- 内容模块：仅摘要、证据、反向条件等独立对象使用边框或淡色背景。
- 禁止卡片套卡片、整页大卡片、装饰性渐变和重阴影。
- 交互选中态统一使用 `--accent`、`--accent-soft`；键盘焦点继续使用 `--highlight`。
- 深浅色模式使用同一组语义变量，不在页面 CSS 中写死颜色。

## 6. 响应式

- `<= 820px`：详情页右栏移动到正文之前，以便先读取关键事实。
- `<= 700px`：专题列表切换为单列。
- `<= 560px`：右栏卡片切换为单列，胶囊导航允许横向滚动。

## 7. 实现入口

- 全局变量与共享组件：`src/css/global.css`
- 专题：`src/css/arcs.css`
- 方向：`src/css/directions.css`
- 事件：`src/css/detail.css`
- 方法：`src/css/methods.css`

新增页面必须先复用共享类；只有页面特有的内容结构才进入页面 CSS。
