# EpochArc 页面设计系统

本规范是全站页面结构与视觉表现的唯一基准。首页可以保留入口页需要的居中叙事，其余页面统一使用同一套内容网格、返回导航、标题层级、信息模块和页脚。

> 状态：页面骨架与排版层级规范已于 2026-07-28 应用于信息节点、方向详情和专题详情三类生产页面。独立验证样例保留在 `drafts/typography-system-preview/`，用于后续回归比较。

## 1. 页面骨架

- 顶部导航：全站复用 `.topnav`，高度 64px；当前栏目使用 `aria-current="page"` 显示蓝色选中态。
- 非首页内容宽度：`--container: 960px`，左右留白由 `--gutter: 24px` 控制。
- 非首页页面：统一使用 `.site-page`。
- 返回入口：统一使用 `.page-back`，位置在标题区域之前；列表页返回时间轴，详情页返回对应列表。
- 页脚：统一使用 `.pagefoot`，只保留 RSS / Atom 与方法和来源两个入口。

## 2. 标题与阅读层级

- 非首页标题全部左对齐，使用 `.page-header`、`.page-kicker`、`.page-title`、`.page-lead`。
- 同一语义角色必须使用同一字号，不得在专题、方向、事件 CSS 中分别创建另一套层级。
- 元信息使用 `.page-meta-row` 或右侧信息栏，不在不同页面重新定义字号和间距。
- 首页可使用居中大标题，但页头、按钮、颜色、字体与页脚仍需遵循本规范。

### 2.1 排版角色

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 页面主标题 | `clamp(36px, 4.2vw, 44px) / 1.08` | 800 | 每页仅出现一次，按内容列自然换行 |
| 页面导语 | `17px / 1.65` | 400 | 主标题下的页面说明 |
| 一级栏目标题 | `20px / 1.35` | 700 | 事件摘要、影响评估、章节、已观察信号 |
| 条目标题 | `16px / 1.45` | 700 | 单个影响、信号、判断、来源标题 |
| 阅读正文 | `15px / 1.7` | 400 | 摘要、专题叙述、方向论证 |
| 辅助说明 | `14px / 1.65` | 400 | 信号解释、受影响群体、来源摘要 |
| 元数据 | `12px / 1.5` | 500–700 | 日期、类别、评分、URL、来源数量 |
| 上位标签 | `11px / 1.4` | 700 | `NARRATIVE ARC`、`OBSERVED · PRODUCT` 等 |
| 胶囊文字 | `11px / 1.2` | 600 | 状态、分类和短操作 |

实现时统一映射为语义变量：

```css
--type-page: clamp(36px, 4.2vw, 44px);
--type-lead: 17px;
--type-section: 20px;
--type-item: 16px;
--type-body: 15px;
--type-support: 14px;
--type-meta: 12px;
--type-overline: 11px;
```

### 2.2 字重、颜色与对齐

- 800 只用于页面主标题；栏目标题和条目标题统一使用 700。
- 正文使用前景色；只有辅助说明、元数据和上位标签使用 `--muted`。
- 不以浅灰正文制造层级。承载核心论点的句子必须使用正常前景色。
- 正文不使用字距；主标题可使用 `-0.04em`，栏目标题可使用 `-0.018em`。
- 等宽字体只用于上位标签和元数据，不用于正文或完整标题。
- 中文上位标签不强制大写；英文上位标签可使用大写和 `0.055em` 字距。
- 所有内容页左对齐。居中排版仅限首页入口叙事。
- 页面主标题使用自然换行，不使用 `text-wrap: balance` 提前截断行宽；同时避免产生只剩一两个词的孤行。

### 2.3 阅读宽度

- 详情页主内容列在宽屏使用完整 912px；页面标题区、摘要、章节正文、洞察、评估和证据说明都与这条内容边界对齐。标题区不得延伸到右侧信息栏。
- 不在 912px 主内容列内部再设置固定的 680px 正文上限。模块内文字使用模块扣除左右内边距后的可用宽度，连续正文直接使用主内容列宽度。
- 表格、来源、关系图和证据账本同样占满主内容区；需要操作列时，从可用网格中明确分配，不通过压缩正文制造空白。
- 模块边界、文字起点、分隔线和相邻模块必须共享同一条左右对齐线，禁止出现“外框很宽、正文悬空在左侧”的双重边界。
- 右侧信息栏不得压缩阅读宽度；宽屏时位于主内容区外，窄屏时移动到正文之后。

### 2.4 纵向节奏

| 场景 | 间距 |
|---|---:|
| 页面标题区域到正文 | 40–48px |
| 一级栏目之间 | 48px |
| 上位标签到栏目标题 | 6px |
| 栏目标题到说明 | 12px |
| 栏目说明到内容列表 | 24px |
| 内容条目之间 | 20–24px |
| 标准模块内边距 | 20–24px |

优先使用留白和细分隔线建立结构；不要依靠不断增加卡片、背景色或标题字号来分区。

### 2.5 各页面的应用

- 事件详情：页面栏目使用一级栏目标题；影响项使用条目标题；正文使用阅读正文；受影响群体、URL 和证据状态使用辅助说明或元数据。
- 首页时间轴展开：属于嵌入式紧凑组件，可以使用 14px 正文和 12px 栏目标签，但不得反向定义独立详情页。
- 专题详情：章节标题使用一级栏目标题，不再使用 22px / 800；章节叙述使用阅读正文；核心洞察只是强调模块，不创建新的正文规格。
- 方向详情：`证据轨迹` 是上位标签，`已观察信号` 是一级栏目标题，单个信号使用条目标题；信号解释使用辅助说明。
- 方向来源：列表中只显示来源数量和一个操作入口；展开后显示来源列表，不重复堆叠 `Source` 胶囊。
- 方法页：使用相同的栏目标题、正文和元数据规格，不创建文档专属字号。

### 2.6 标准阅读顺序

所有内容页面遵循：

`页面主标题 → 页面导语 → 上位标签（可选）→ 一级栏目标题 → 条目标题 → 正文 → 元数据 / 操作`

同一区域最多同时展示两层标题。不得同时出现“上位标签 + 大栏目标题 + 第二个上位标签 + 条目标题”四层竞争关系。

## 3. 列表页

- 专题列表、方向列表均使用 960px 内容宽度和左对齐标题区域。
- 列表页必须有返回时间轴入口。
- 专题适合使用克制的双列内容卡；方向适合使用信息账本式列表。
- 卡片只承载可独立点击的内容对象，不用卡片包裹整个页面。

## 4. 详情页

- 桌面宽屏统一使用 `.page-with-rail .page-layout`：主内容保持标准宽度，右侧信息栏固定 `--rail-width: 220px`，间距 `--page-grid-gap: 36px`，侧栏位于内容区域外。
- 右侧信息栏使用 `.page-rail`、`.rail-card`、`.rail-facts`，展示日期、状态、评分、时间跨度、事件数等快速事实。
- 三类详情页都在右侧信息栏使用 `.rail-link-list[data-page-toc]` 展示本页大标题目录；滚动到当前章节时以蓝色和 `aria-current="location"` 标记。
- 专题详情：章节目录只保留在右侧信息栏，不再使用正文上方的胶囊式横向导航；摘要使用单一强调模块；章节正文保持连续阅读。
- 方向详情：右栏展示窗口、证据、信号、来源和复核日期；正文展示基线、论点、信号、反向条件与来源。
- 事件详情：右栏展示日期、分类、重要度、共识和影响指数；正文展示摘要、影响、证据与关联事件。
- 方法页：右栏作为本页目录和统一定义说明；正文是全站规则的唯一来源。
- 事件详情的“返回时间轴”必须回到不含 `event` 查询或片段参数的时间轴；从展开节点进入详情前也必须清理当前历史项，保证页面返回和浏览器返回都恢复折叠状态。
- 返回时间轴时必须恢复到来源节点附近的阅读位置，不能默认回到页面顶部。内部跳转可临时使用不可索引的 `#return=<event-id>` 片段记录节点与视口锚点，定位完成后立即清理片段。

## 5. 组件规则

- 胶囊：只用于返回、当前章节、状态和短标签；使用 `--radius-pill`。
- 内容模块：仅摘要、证据、反向条件等独立对象使用边框或淡色背景。
- 禁止卡片套卡片、整页大卡片、装饰性渐变和重阴影。
- 交互选中态统一使用 `--accent`、`--accent-soft`；键盘焦点继续使用 `--highlight`。
- 彩色左侧线必须表达真实状态：蓝色只用于实际选中、激活或当前位置；红色用于反向条件、风险或阻断。独立详情页、静态摘要、普通信号和普通洞察不得使用蓝色左线作装饰。
- 深浅色模式使用同一组语义变量，不在页面 CSS 中写死颜色。

## 6. 响应式

- `< 1440px`：详情页右栏移动到正文之后，并以两列卡片展示；正文先保持完整阅读顺序。
- `< 1440px`：右栏不再位于阅读侧边，因此隐藏右栏目录卡，避免在正文末尾出现失去导航价值的目录。
- `<= 700px`：专题列表切换为单列。
- `<= 560px`：右栏卡片切换为单列，胶囊导航允许横向滚动。

## 7. 实现入口

- 全局变量与共享组件：`src/css/global.css`
- 专题：`src/css/arcs.css`
- 方向：`src/css/directions.css`
- 事件：`src/css/detail.css`
- 方法：`src/css/methods.css`

新增页面必须先复用共享类；只有页面特有的内容结构才进入页面 CSS。
